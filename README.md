# dlm6693.github.io

Personal console site for [David Miller](https://github.com/dlm6693).

```bash
npm install
npm run dev
```

Deploys to GitHub Pages on push to `main`. Contribution city SVGs sync from the [profile repo](https://github.com/dlm6693/dlm6693) via Actions.

## LinkedIn Featured (manual)

1. Open [your LinkedIn profile](https://www.linkedin.com/in/david-l-miller) → **Add profile section** → **Featured** → **Add link**
2. URL: `https://dlm6693.github.io`
3. Title something like `Personal site` / `Console profile`

LinkedIn can’t host the live console; Featured is the way to point people here.
